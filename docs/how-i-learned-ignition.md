# How I Learned Ignition

Use this in interviews and while building. Do not skip [Inductive University](https://inductiveuniversity.com/) or the [Ignition User Manual](https://www.docs.inductiveautomation.com/) because an assistant explained a click.

## What to say

**Weak:** “An AI walked me through Designer.”

**Expected:** “I built a monitoring app in Ignition Maker Edition and used Inductive University and the manual when I did not know the click.”

If you want **Core certification**, those videos **are** the curriculum. An assistant cannot replace that.

Timing, PLC literacy, MQTT, and OT security: [adjacent-skills.md](adjacent-skills.md). Do not pause Part 2 to “master MQTT.”

## How to learn while building

Do not watch a complete Ignition course before the next checklist item. Use this loop:

```text
Build one step
    -> encounter a specific gap
    -> watch one Inductive University video or open one manual page
    -> apply it immediately
    -> confirm it works
    -> record what was learned
```

An assistant is useful for **order**, **interview language**, and a first guess at the next click. Designer UI changes by version. Official material is the source of truth. Cite IU and the manual, not the assistant.
